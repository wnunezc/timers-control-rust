# 0.1.1 Alpha — soporte básico de Linux

Esta versión añade una GUI Linux nativa a los temporizadores existentes. En Linux
se pueden crear, configurar, pausar, continuar y detener cuentas mediante la
entrada inferior, con fuente de tamaño constante y alarma del tema del sistema.
Se conserva el backend Windows x64 y la lógica compartida de temporizadores.

## Plataformas y distribuibles

- Linux x86_64 con glibc y Wayland/xdg-shell: paquete tar.gz con el ELF, guía,
  avisos de componentes y checksum interno.
- Windows x64: EXE con runtime C estático.
- SHA256SUMS.txt: checksums de ambos archivos descargables.

Linux se validó en Void/glibc 2.41, Sway 1.12 y WSL 2, con renderizado por software.
El usuario confirmó la prueba gráfica manual dentro de Sway/WSLg. No se declara
compatibilidad con toda distribución, musl, Linux de 32 bits ni Windows XP.

Tamaños de esta compilación: EXE Windows 227 840 bytes; ELF Linux sin comprimir
345 184 bytes; tar.gz Linux con guía y avisos 169 965 bytes. El ELF necesita las
bibliotecas compartidas del sistema, cuyo tamaño no está incluido en esa cifra.

## Implementación

- Wayland nativo sin XWayland, GTK, Wine ni crates externos.
- Dibujo Cairo en buffers compartidos, con liberación de tamaños anteriores.
- Edición UTF-8, Ctrl+A/Ctrl+U, repetición de teclas y desplazamiento de la lista.
- Bucle síncrono sin hilos propios ni runtime async; espera bloqueante en reposo.
- Sonido completo `/usr/share/sounds/freedesktop/stereo/complete.oga`, decodificado
  por bloques de 16 KiB mediante libsndfile y reproducido con PulseAudio simple.
  Requiere el paquete sound-theme-freedesktop. Un fallo de audio muestra un error
  y mantiene la aplicación abierta.

Las bibliotecas nativas Linux se instalan desde la distribución y no se incluyen
en el paquete. Consultar [dependencias y compilación](../LINUX.md).

## Validación y límites

14 pruebas Linux y 12 Windows, compilaciones release, formato, Clippy y Rustdoc.
Integración Linux: comandos y estados, vencimiento, UTF-8, entrada inválida,
scroll, redimensionado, audio capturado en salida virtual y errores de conexión.

El audio es síncrono y bloquea la GUI durante su reproducción; libpulse puede
crear un hilo auxiliar temporal. Faltan persistencia, recurrencias, rutas de audio
configurables, extracción de segmentos, portapapeles e IME. DPI por monitor,
suspensión y hardware Linux físico necesitan validación adicional.
