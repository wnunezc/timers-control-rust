# 0.1.2 Alpha

Parche para el inicio de la aplicación en Linux.

## Corregido

- El mapa de teclado podía rechazarse aunque fuera válido, mostrando `XKB-822` o `xkbcommon rechazó el keymap` e impidiendo abrir la aplicación.

Windows no tiene cambios funcionales en esta versión.

## Actualizar

Descarga el paquete de tu sistema desde
[0.1.2 Alpha](https://github.com/wnunezc/timers-control-rust/releases/tag/v0.1.2-alpha)
y sustituye el ejecutable anterior. En Linux, usa el ELF incluido en el nuevo tar.gz.
Los requisitos de ejecución son los mismos que en 0.1.1.

La descarga incluye el paquete Linux x86_64, el EXE Windows x64 y `SHA256SUMS.txt`.
Consulta la [guía Linux](../LINUX.md) para instalar las bibliotecas necesarias.

El soporte sigue en alpha. Los detalles del fallo y de su prueba de regresión
están en la [documentación de desarrollo](../development/TESTING.md#regresión-xkb-822).
