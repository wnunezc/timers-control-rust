# 0.1.2 Alpha — corrección del teclado Wayland

Corrige un fallo de inicio Linux que podía mostrar
`xkbcommon: ERROR: [XKB-822] Failed to parse input xkb string` y
`Timer-Rust: xkbcommon rechazó el keymap` aun con un mapa de teclado válido.

La versión anterior leía el descriptor recibido desde su posición actual. Si
estaba al final, entregaba una cadena vacía a xkbcommon. Ahora lee exactamente
el tamaño anunciado desde el byte cero sin modificar la posición compartida y
valida el terminador NUL. No añade dependencias, hilos ni actividad periódica.

## Descargas

- Linux x86_64 con glibc y Wayland: tar.gz con ejecutable, guía, avisos y checksum
  interno. Sustituir el ejecutable anterior por el de este paquete.
- Windows x64: ejecutable recompilado para esta versión; sin cambios funcionales.
- SHA256SUMS.txt: checksums de ambos distribuibles.

Tamaños: ELF Linux 402 528 bytes, paquete Linux 200 107 bytes y EXE Windows
228 352 bytes. El paquete no incluye las bibliotecas compartidas del sistema.

Las bibliotecas nativas Linux se instalan desde la distribución; consultar la
[guía Linux](../LINUX.md). Se conservan los requisitos y límites de la 0.1.1 Alpha.
No se declara compatibilidad con Linux musl, todas las distribuciones ni XP x86.

## Validación

La regresión reproduce los mensajes originales antes de la corrección usando el
callback real y un mapa válido con el descriptor situado al final. El parche
acepta posiciones inicial, intermedia y final, interpreta Escape y conserva la
posición compartida. Pasan 21 pruebas Linux y 12 Windows, formato, Clippy y Rustdoc
con advertencias como errores, y las compilaciones release.

Arranque y cierre comprobados en Void Linux/glibc con Sway aislado en WSL, sin
errores ni advertencias en el registro propio. Falta confirmar el parche en el
equipo que reportó el problema; esta prueba no acredita todas las configuraciones.
